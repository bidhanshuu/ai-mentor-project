# RAG Dataset Template

This folder is a starter template for building a real dataset for AutoMentor.

Suggested structure:

```text
rag_dataset_template/
  README.md
  raw/
    calculus/
    php/
    dsa/
    japanese/
  processed/
    manifest.csv
    chunks.jsonl
```

Use `raw/` for original files and `processed/` for cleaned metadata and chunks.
