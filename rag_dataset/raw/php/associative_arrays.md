Associative arrays in PHP store data using named keys instead of numeric indexes. They are useful when representing structured information such as student records, user details, or configuration values.

Students commonly confuse associative arrays with indexed arrays. Because of that, they sometimes try to access values using numeric positions even when the array was built with named keys. In lab work, this causes undefined index errors and incorrect output.
