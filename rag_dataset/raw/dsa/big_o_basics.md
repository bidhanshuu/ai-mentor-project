Big-O notation describes how the cost of an algorithm grows as input size increases. In most academic questions, students should identify the dominant loop or repeated operation and ignore constant factors.

If one loop runs n times, the time complexity is usually O(n). If nested loops both run n times, the complexity is usually O(n squared). Students lose marks when they describe the algorithm in words but do not express the final growth rate correctly.
