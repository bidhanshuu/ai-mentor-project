A recursive function must always have a base case. The base case is the stopping condition that prevents infinite calls and stack overflow. It handles the smallest version of the problem directly.

One reliable coding habit is to write the base case before writing the recursive step. This reduces logical errors and makes recursion easier to explain in viva or lab evaluation.
