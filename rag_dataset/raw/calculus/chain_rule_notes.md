The chain rule is used when one function is written inside another function. In composite functions, students should identify the outer function and inner function before differentiating. The derivative is found by differentiating the outer function first and then multiplying by the derivative of the inner function.

A common student mistake is to apply only the power rule and ignore the inner expression. This leads to incomplete answers in exam questions. A good solving pattern is to first rewrite the expression mentally as f(g(x)), then apply the chain rule step by step.
